## 完成门槛与后续

迁移仍不标记为全部完成。剩余验收包括更多历史缓存形态、长篇导出排版和跨平台文件管理器的实机验收。macOS 文件定位命令及路径边界已以子进程替身测试。已用 15 项浏览器流程覆盖设置、书库、迁移入口、图谱控件及窄屏边界；这不等于逐项进行了人工验收。

PDF.js、Tauri 进程管理、安装包属于桌面化后续阶段，不是旧界面能力已迁移的证据。当前浏览器 PDF iframe 的兼容性限制仍存在。

## 本轮验收补充

- 论文编辑的取消、关闭和 Escape 统一检查未保存修改；论文及应用设置的刷新/离开页面增加浏览器原生提示。拒绝丢弃后草稿保留。
- 外观保存发生 409 冲突时保留草稿；取消退出保留编辑；确认丢弃不更改已保存主题。
- 导出下载采用服务器的论文文件名；PDF 浏览器实例使用独立临时配置目录并关闭默认页眉页脚，避免泄露本地临时 HTML 路径。
- E2E 夹具使用有效双页 PDF 和结构化速读缓存；PDF/PPTX 导出实际执行并解析文件，而非模拟下载。
- 模型错误和重试使用合成响应，断言仅发送 useSaved 引用。未调用真实模型，不能据此宣称真实供应商生成链路已验收。
- 本地 68 项 Python 回归、15 项浏览器流程通过；生产构建通过。
