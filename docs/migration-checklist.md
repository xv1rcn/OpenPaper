# 旧入口迁移核对（2026-11-21）

基线为仓库旧 `index.html`、`quick-reading.html`、`stats.html` 的实际控件与行为。入口跳转不等于功能验收完成；下表区分已接入、替代方式和仍需验证的内容。旧源码暂不删除。

| 原能力 | Vue 入口与处理 | 当前验收 |
|---|---|---|
| 外观和速读配置 | 统一「设置」中的「外观」「速读」 | 持久化、切换页签保留草稿、失败恢复已测试；移除旧版外观导入和存储说明 |
| 模型地址、密钥、模型列表、预算、测试连接 | 设置 → 速读 | 原回归通过；真实付费调用未执行 |
| 旧浏览器密钥迁移 | 仅检测到旧配置时显示导入 | 保留，避免已有用户丢失凭据；与已移除的外观导入不同 |
| 搜索、来源、排序、未读与标签 AND/OR | 书库与更多筛选 | 已接入；补回 `/` 搜索快捷键及筛选标签搜索 |
| 分组、折叠、拖动排序 | 书库 → 按标签分组 | 已接入，顺序刷新保留；提供键盘可用的上下移动按钮 |
| 标题、作者、年份、来源、笔记、BibTeX | 论文编辑 | 已接入；补回现有标签建议 |
| 论文卡片笔记 | 展开阅读笔记 | 已补齐；仅为 http/https 网址生成链接，其他文本按纯文本显示 |
| 速读状态与入口 | 卡片显示未生成、运行中、成功、失败 | 已补齐；从轻量缓存索引读取，不改写元数据；状态随书库刷新更新 |
| 打开 PDF、所在目录 | 论文编辑、阅读工作区 | 已接入；浏览器 file:// 原始源文件跳转不保留，以受控 PDF 地址替代 |
| 生成选项和进度 | 阅读工作区 | 已接入；补回缓存选项初始化，运行中禁止再次发起生成 |
| 速读结构化内容、图表、原文对照 | 阅读工作区 | 已接入；图表呈现复用原归一化逻辑，真实历史缓存的多版本视觉核对仍需补充 |
| PDF/PPTX 报告 | 阅读工作区 | 已接入既有导出服务；新页面真实导出文件内容验收仍待补充 |
| 元数据、Markdown、省流总结导出 | 导出与管理 | 已接入；原始 JSON 不丢扩展字段 |
| 浏览器绑定 metadata.json | 后端统一写入论文库 | 被后端自动持久化替代，不再要求浏览器文件授权 |
| 日志刷新、搜索、复制、自动滚动 | 导出与管理 → 运行日志 | 已接入；复制需浏览器剪贴板权限，失败会提示 |
| 回收站恢复与永久删除、标签删除 | 回收站、导出与管理 | 已接入原接口 |
| 月度、年度、来源、标签统计及已读比例 | 统计面板 | 已接入；采用条形数值和总览，不复刻旧饼图样式 |
| 累计增长、周新增、阅读进度、热力图、近期新增、标签年份矩阵 | 统计面板 | 已补齐；统计函数测试覆盖跨年周与无效日期；阅读进度明确基于加入时间，不伪装实际阅读日期 |
| 论文知识宇宙 | 统计面板 → 论文关系 | 标签/来源/年份分组、仅已读、隐藏论文、拖动缩放、重置、论文跳转已接入；使用确定性布局，未复刻旧物理力导向布局 |

## 完成门槛与后续

迁移仍不标记为全部完成。剩余验收包括更多历史缓存形态、真实导出内容和文件系统操作的端到端验收。已用 11 项浏览器流程覆盖设置、书库、迁移入口、图谱控件及窄屏边界；这不等于逐项进行了人工验收。

PDF.js、Tauri 进程管理、安装包属于桌面化后续阶段，不是旧界面能力已迁移的证据。当前浏览器 PDF iframe 的兼容性限制仍存在。
