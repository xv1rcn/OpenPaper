## M1 交付范围

1. 显式区分资源目录与论文库目录；保留未指定参数时的旧启动方式。
2. 移除 server 模块导入时的数据迁移，改为显式 bootstrap。
3. 论文扫描不再生成 HTML 或启动 build.py 子进程；旧 build.py 作为兼容入口。
4. 每个 HTTP server 持有自己的运行上下文，不依赖进程 cwd 和可变路径全局变量。
5. 文件服务使用白名单与真实路径边界检查；不公开仓库、配置、回收站或任意文件。
6. 支持 `--library-root`、`--resource-root`、`--port 0` 和就绪事件。
7. 原有标签/回收站测试，加上路径隔离、无副作用导入、独立扫描、HTTP 访问边界与多实例测试。

## 后续必须解决的项目

- 旧页面仍使用 localStorage 保存 API Key，M1 不宣称已解决凭据持久化。
- 旧端点仍是开发兼容接口；正式桌面接入前完成 Host/Origin/令牌策略、请求体上限与受控文档传输。
- 原 JSON 业务存在并发读改写风险；引入统一写入队列或锁，验证监控/编辑/恢复/生成并行场景。
- 速读结果身份需纳入模型、生成选项、提示词与解析器版本；不能只依赖 PDF 指纹。
- 不假定所有导出都自包含：当前 PDF 报告导出还需浏览器可执行文件，M6 需明确替代或打包策略。
- Python 版本与 PyMuPDF 的实际安装矩阵、Poppler 分发许可、上游 OpenPaper 许可状态需在公开发布前核实。
- 第一版不实现账号、云同步、支付、EPUB、TTS 与移动端。

## 迭代约定

- 保留用户现有论文、速读和浏览器配置，不自动清理或复制真实密钥。
- 不在日志、Git、测试夹具或截图中保存密钥。
- 保持每个阶段可回退；迁移测试使用临时目录。
- 大规模 UI 替换前建立书库与阅读工作区状态清单，逐项验证快捷键、焦点、空状态、加载、错误与恢复。

## M2 第一批：后端配置服务（2026-11-21）

- 新增 `backend/settings/store.py`：版本化 JSON、原子替换、修订号冲突检测和系统凭据库适配器。macOS 使用 Keychain，Windows 使用 Credential Manager，Linux 使用 Secret Service；不自动选择第三方明文后端。
- 普通配置默认位于用户应用数据目录，可用 `--config-root` 指定独立位置；读取默认配置不创建目录。
- 密钥采用新条目写入、读回验证、替换配置引用、清理旧条目的顺序。写入失败保留原配置；清理失败返回警告。进程在两阶段之间崩溃可能遗留无引用凭据，后续需增加受控清理。
- `GET /api/settings` 不返回密钥或凭据引用。`POST /api/settings` 要求本地 Host、同源 Origin（若提供）、JSON、自定义请求头，限制请求大小；旧修订号返回 409。
- 更换 API 地址时必须重新提供密钥。此模块只负责存储；尚未将保存的凭据接入生成端点，避免在旧接口保护未完成时暴露凭据使用能力。
- 本机 46 项测试通过，包含 16 项新增配置/HTTP 测试；自动化凭据测试使用内存替身。另外已用随机合成凭据在本机 macOS Keychain 验证写入、读回与删除，全程未使用真实 API 密钥；Windows/Linux 原生凭据库仍待验证。
- 修复 Windows Explorer 辅助函数缺失 `time` 导入；将 CI 冷启动等待上限从 15 秒调为 60 秒；矩阵不再因一个失败取消其他任务。
