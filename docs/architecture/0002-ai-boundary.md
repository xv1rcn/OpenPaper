# ADR 0002：保留 Python 应用服务，隔离 AI 调用

状态：架构方向已确定；LangChain 适配尚未实施。

OpenPaper 是本地单用户论文应用。后端不仅调用模型，还负责论文导入与索引、元数据、回收站、文件边界、配置及系统凭据、PDF 解析和图像提取、速读缓存与任务进度、PDF/PPTX 导出。这些职责继续作为独立应用服务，不能由 LangChain 替代。

后续先提取模型调用接口：输入消息、图像、结构化输出要求及预算，输出规范化结果、用量与可分类错误。现有客户端作为第一实现；有实际多供应商需求后，再用 LangChain provider adapter 做第二实现。领域层不得依赖框架消息或异常类型。

迁移验收包括结构化输出、流式进度、图像降级、超时与重试、取消、预算约束、敏感错误脱敏及缓存身份。使用录制/合成响应回归，不因框架替换自动调用真实模型。缓存身份未来应包含文档指纹、模型、生成选项、提示词和解析器版本。

LangGraph 仅在需要可恢复多阶段任务、检查点或人工中断时评估；当前优先补齐任务生命周期和桌面单实例。替换框架不解决凭据持久化或桌面分发。
