# ADR 0001 — 本地论文阅读与分析桌面应用

- 日期：2026-11-21
- 状态：已接受，分阶段实施
- 上游基线：RunminG-Lab/OpenPaper，`4ac7205`
- 开发 fork：https://github.com/xv1rcn/OpenPaper

## 产品边界

面向单用户、本地优先的论文阅读和研究。第一版 macOS 优先，路径、进程和打包设计保留 Windows 扩展空间。普通阅读和管理不需要账号、订阅或官方云服务；外部模型费用由用户自己的服务商收取。

Readest 仅作为书库和阅读交互的参考。不基于 Readest 派生，不复制其组件、品牌、资源或服务，不接入其账号、订阅和云 API。现阶段不追求 EPUB、TTS、移动端或云同步的功能覆盖。

## 技术与职责

| 层 | 决策 | 职责 |
|---|---|---|
| 桌面 | Tauri 2 / Rust | 窗口、文件选择、单实例、辅助进程启动与退出、系统集成 |
| 前端 | Vue 3 / TypeScript / Vite | 论文库、阅读工作区、设置、任务交互 |
| UI | shadcn-vue / Tailwind CSS | 基础组件；视觉规范根据阅读场景统一设计 |
| 阅读器 | PDF.js | PDF 渲染、文本层、搜索、页面定位；批注需自行实现 |
| 业务 | Python 辅助进程 | 论文管理、PDF/图表提取、模型调用、结构化速读、导出 |
| 普通配置 | 版本化 JSON | 显式数据目录、原子写入、失败不覆盖、迁移前备份 |
| 凭据 | 系统凭据库 | Python 侧统一访问；不可用时明确报错，不降级明文 |

不同时引入新的前端框架、数据库和文档身份方案。第一阶段保留相对路径 file_key 与既有 JSON 数据，建立后续迁移边界。

## 数据所有权

- Python 是论文数据的唯一写入方；前端与 Tauri 不重复维护论文目录。
- 应用资源目录只读，不能存放用户配置、运行日志或新增论文。
- 论文库根目录包含 `papers/` 和 `.recycle_bin/`。暂时保留 `.quick_reading_cache` 的磁盘格式与相对 URL 以兼容现有结果。
- 已生成速读和关联图像属于用户成果，不是可随意清理的缓存。
- 应用配置、凭据、可重建缓存、日志与论文库分别管理。
- 用户现有文件与浏览器 API Key 不自动迁移或删除。密钥迁移必须在系统凭据库存储验证成功后才清理旧值。

## 通信与生命周期

保留本地 HTTP 作为第一阶段业务接口；仅监听 127.0.0.1。桌面模式将使用系统分配端口、启动握手和每次启动的临时令牌。正式前端由 Tauri 提供，Python 不公开源码、配置、日志和回收站目录。文档与图像使用受控访问。

桌面模式必须覆盖启动失败、就绪超时、退出清理与异常恢复。开发兼容模式不视为已具备这些安全与进程保障。

## 阅读工作区

书库与阅读分离；PDF 和速读/笔记面板可并排调整宽度；保存阅读位置与布局。证据锚点采用文档标识、内容版本、PDF 实际页索引和归一化页面区域，不能用电子书估算页码替代。

先完成导入、查找、阅读、速读生成、保存、重启恢复，再扩展复杂批注、OCR、跨论文问答与同步。

## 不采用的方案

- Readest fork：完整去除账号与官方服务、改变凭据和文档模型会扩大维护范围。
- 从 Readest 抽取界面再迁移 Vue：组件依赖状态和平台服务，抽取并非独立 UI 替换。
- Electron：当前选 Tauri，不同时维护第二种桌面壳。
- 全面重写 Python：保留速读与图表业务，优先改基础设施。

## 仓库目标

`frontend/` 为新前端；`src-tauri/` 为桌面壳；`backend/runtime/` 为启动与路径；`backend/settings/` 为配置与凭据；`backend/library/` 为论文管理；`backend/quick_reading/` 保留分析业务；`docs/` 保存决策与迭代计划。旧页面在新工作流验收后再移除。
