# 桌面测试包验收

当前验收区分原生窗口交互、冻结后端集成、安装包内容验证，不将其中一项通过等同于其余项目通过。

## 自动化覆盖

`python scripts/packaging/verify_bundle.py app|deb|nsis` 先验证安装包中的后端依赖及会话，再执行 `acceptance_backend.py`：

- 从应用包/安装目录提取后端，放在带中文与空格的独立临时目录。
- 通过真实 HTTP 接口导入三页 PDF，验证重复导入去重。
- 保存标题、笔记、标签与已读状态。
- 保存外观、模型端点/名称（不使用真实密钥、不请求模型）。
- 保存第三页阅读位置、对照比例及 PDF 缩放。
- 正常停止后端，删除测试程序副本，复制同版本到另一目录。
- 使用相同测试数据目录启动新进程，验证论文字节哈希、元数据、设置与阅读状态。

这是重启和**同版本程序替换**验证，尚不代表跨版本配置迁移或安装器升级保留数据。测试不写入真实用户的论文库。

## macOS 原生观察

2026-11-23 在 macOS release 应用中完成原生 UI 验证：

- 使用系统文件选择器导入一页合成测试文档 `openpaper-model-check.pdf`，书库显示导入成功，PDF.js 正常显示全文。
- 使用用户已保存的模型配置测试接口，收到有效 JSON 回答；未读取、展示或修改密钥。
- 选择简要模式、关闭图表解读，完成一次真实模型速读生成。摘要保留了合成数据的性质、查询延迟和索引构建成本，以及不能推广到真实场景的限制。
- 使用 ⌘Q 完整退出并重新启动应用，后端端口发生变化；文档和速读缓存恢复，生成时间及摘要保持一致，未重新生成。
- 重启后再次测试接口成功，确认已保存凭据能够继续用于模型调用。

测试文档保留在本机书库，方便人工复核。本次未验证多页翻页、搜索、缩放及非默认阅读位置恢复。此前用户说明启动测试可能被手动关闭，不将该现象归因为应用启动故障。

上述观察中的缺失缓存报错、英文内部字段直出已在后续界面清理中修复；简要模式已调整生成约束，未重新付费生成验证篇幅。正文信息架构与排版的进一步重设计在独立分支处理。

## 系统凭据库

冻结后端支持显式诊断命令 `openpaper-backend --self-check-vault`。它只在独立服务名 `org.openpaper.acceptance` 下使用随机账户写入合成测试值，读回验证后删除；不读取或修改实际 OpenPaper 模型凭据。此检查仅应在有可用系统凭据库的桌面会话中手动执行，不在无凭据库的 CI 中伪装通过，也不自动接受系统授权提示。

## 仍需验收

- PDF.js 多页翻页/搜索/缩放、重开应用恢复非默认阅读位置。
- Windows / Linux 桌面会话中真实凭据库读写及权限异常提示。
- 原生关闭时未保存草稿提示、后端崩溃恢复。
- 旧版本到新版本的真实安装器升级、卸载后数据保留策略。

此前在受限命令执行环境中，冻结后端及宿主 Python 的合成凭据写入均返回 `PasswordSetError: (100001, 'Unknown Error')`，原始失败原因未得到确定。随后用户报告原生应用保存密钥并重启成功；上述原生 UI 验证进一步确认了重启后使用已存密钥调用模型成功。两类执行环境的结果应分别记录，不能将命令环境失败等同于桌面应用不可用。未读取用户现有密钥，也未自动接受授权提示。

## 本次 PR 收尾

- 阅读器原型和设计文档已独立保存在 `feat/reader-redesign`（cf0e3aa），当前分支不包含该原型。
- 新增离线复制迁移工具，测试覆盖论文内容、元数据扩展字段、内嵌速读、旧图像缓存、备份、回收站、重复 bootstrap 以及源文件不变；拒绝已有目标、嵌套目录及符号链接。真实用户书库未移动。

- 新增启动错误页、后端退出监测、保留草稿的恢复提示和原生退出确认协议；前端逻辑测试覆盖拒绝、确认、多草稿及重复退出请求。Rust 编译检查通过。
- 本轮原生界面连接超时，尚未完成启动失败、后端退出与关闭确认的实机故障注入；必须继续列为待验收，不能用编译与单元测试替代。
